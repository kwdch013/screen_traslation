# ADR-0006 Python依存とモデル導入の候補

## 状態

2026-10-29、提案。Python 3.14依存・実推論・性能は未実施。#60のPoC結果で #57 が最終選定する。[索引・検証課題](README.md)。

## 対象要件

REQ-F-004、REQ-F-008、REQ-F-011、REQ-F-012、REQ-NF-002、REQ-NF-003、REQ-NF-005、REQ-NF-007、REQ-NF-009、REQ-NF-010。

## 背景

Tesseract + Argos英日、Linux x86_64/Python 3.14/Docker、CPU動作は承認済み要求。Pythonパッケージ・ネイティブ依存・学習データ・英日モデルの互換性と品質をまだ確認していない。準備不足をhealth成功だけで見逃してはならない。

## 比較

| 候補 | 利点 | 制約・今回の判断 |
| --- | --- | --- |
| 明示した導入工程で固定モデルを取得・検証しvolumeへ保存 | 稼働時オフライン、モデル寿命とアプリ更新を分けられる | manifestと取得元/破損/更新復旧の設計が必要。推奨候補 |
| 固定モデルをイメージへ同梱 | 起動時の外部通信を減らせる | イメージサイズ・再配布条件・更新が結び付く。代替候補 |
| 起動や各翻訳でlatestを自動取得 | 初期操作を減らせる | 再現性・通信境界・期限・更新失敗が不明確になるため不採用 |
| Python版変更/クラウド翻訳/新規LLM | 一部の依存/品質問題を避ける可能性 | 要求または範囲の変更になる。無断採用せずOwner判断へ戻す |

## 採用候補

Python 3.14コンテナでTesseract本体/英語学習データ、Python依存とArgos英日モデルを固定する案を推奨する。モデルは管理者の明示導入でのみ、許可した取得元からHTTPS取得し、版・サイズ・SHA-256・利用/再配布条件をmanifestと照合する。digestは信頼できる配布元情報または管理者が検証したmanifestとして固定し、取得物自身の自己申告値だけで真正性を判断しない。

取得/検証/展開は一時領域で実施し、成功後に原子的に有効化する。アーカイブの展開先逸脱・過大展開・欠損を拒否し、有効モデルを破損物で上書きしない。通常画像処理で外部翻訳へ送信せず、画像・原文・訳文をモデル導入ログにも残さない。初回取得に必要な外向き通信と通常推論の通信境界を分ける。モデル保存先は設定/volumeで与える。

healthはプロセスの生存、readyは固定モデルの存在/検証/ロード/warmup成功を示す別状態にする。全ネットワークAPIのTLS/認証はhealth/readyにも適用する。readyでなければ翻訳を受理せず状態/復旧を案内し、無制限取得や再試行をしない。取得先・再試行上限/待ち・検証失敗後の復旧は #57/#77/#103 で固定する。

## 検証と確定担当

Q-12は #60 でLinuxの資源制限付きPython 3.14コンテナに依存を導入し、スタブではない実OCR/英日翻訳を試す。モデル固定版とイメージdigest、導入/起動/warm時間、失敗、CPU/メモリ、一般化した環境を記録する。導入済み120秒、空領域から1800秒（合意済み通信条件・モデル合計1 GiB以下）、2 CPU/4 GiB、warm p50 2000 ms/p95 4000 msを評価し、未測定は未実施とする。

品質は #109 の固定OCR200枚（明瞭群CER 5%以下/複雑背景群15%以下）、翻訳100文の主旨90文以上・重大逆転0件・用語20件100%、300件×3回の遅延と8時間/失敗率1%以下を[受入計画](../../acceptance.md)の条件で最終判定する。少数PoCを全基準の合格にしない。#57は #60 の互換性と性能の制約を設計へ反映し、#77/#81/#103へモデル導入/readyを引き渡す。

## 影響

Python 3.14の対応wheelやネイティブ依存が不足した場合、ロック可能な対応版/再現可能なビルドを比較する。CPU予算/品質が不達なら工程別の原因と測定値、対象要件ID、代替案をOwnerへ提示する。Python版や性能基準、外部送信の要求を自動で変更しない。専用GPUによる成功をCPU要件の合格に代えない。モデルと設定/辞書、資格情報を別々にバックアップ/更新する。

## 根拠

2026-10-29確認: [Tesseract公式文書](https://tesseract-ocr.github.io/tessdoc/)と[Argos公式文書](https://argos-translate.readthedocs.io/en/latest/)はOCR/オフライン翻訳とモデル導入の候補根拠。これらだけではPython 3.14と本アプリの依存/モデル/性能を保証しない。[要件書](../../../../requirements/version_1/requirements.md)と受入計画をQ-12の判定基準とし、固定版の実行結果は #60/#109 で取得する。
