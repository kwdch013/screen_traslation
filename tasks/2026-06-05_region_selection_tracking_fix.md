# 2026-06-05 範囲選択の追従ずれ修正

## 背景
- 開始ボタン押下後の範囲選択で、ドラッグ中の矩形や保存される選択範囲がマウス位置にうまく追従しないことがあった。
- キャンバス相対座標だけで範囲を計算していたため、マルチモニタ配置やDPIスケーリング環境で座標系がずれる可能性があった。

## 実装
- 範囲選択の開始、ドラッグ、確定を `event.x_root` / `event.y_root` の画面絶対座標基準に変更した。
- 描画用には画面絶対座標を仮想スクリーン原点からのキャンバス座標へ変換するようにした。
- 逆方向ドラッグや小さすぎる選択範囲を扱うヘルパーを追加した。
- デスクトップアプリ起動時にDPI aware化を試行し、Tk座標とキャプチャ座標のずれを抑制するようにした。

## 確認
- `.venv` で `python -m unittest src.tests.test_desktop_app` を実行し、11件成功。
- `.venv` で `python -m unittest discover -s src/tests` を実行し、66件成功。
- `docker compose run --rm app` は、この環境で `docker` コマンドが見つからないため未実行。
