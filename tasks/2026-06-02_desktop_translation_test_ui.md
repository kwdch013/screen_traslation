# 2026-06-02 デスクトップ翻訳テストUI修正

## 作業内容

- 翻訳テストが常に素通し翻訳器を使っていたため、実行時と同じArgos翻訳器を優先して使うように変更した。
- Argos翻訳器または英日モデルが未導入の場合でも、翻訳テストの初期例 `New Game` は辞書一致で `ニューゲーム` と表示できるようにした。
- 辞書登録欄に「英語」「日本語」のラベルを追加し、入力例として `New Game` と `ニューゲーム` を初期表示した。
- 実行ボタンは停止中に「開始」のみ、開始中に「停止」「終了」のみが表示されるようにした。

## テスト

- `src/tests/test_desktop_app.py` を追加し、翻訳テスト用の既定例とユーザー辞書優先を確認する。
- `.venv` にArgos Translateの英日モデル `translate-en_ja.argosmodel` を導入した。
- Argosの翻訳モデルはGit submodule向けのソースリポジトリではなく、`.argosmodel` パッケージとしてArgos側の管理領域にインストールされるため、submodule化は行っていない。
