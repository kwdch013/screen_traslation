# OCR誤表示の抑制と透明度の動的変更

## 対応内容
- OCRが前回のオーバーレイ表示だけを読み取った場合、古い翻訳結果を保持せず空表示へ戻すように変更。
- OCR後処理で、`Start` や `Inventory` のような単語単体のUIラベルを翻訳候補として残すように変更。
- オーバーレイ透明度スライダーを実行中のオーバーレイへ即時反映するように変更。
- 透明度の現在値をパーセント表示するラベルを追加。

## テスト
- `py -3.14 -m unittest discover -s src/tests`
- `py -3.14 -m compileall -q src/app`

## 補足
- 透明度は0.1から1.0の範囲に正規化して反映する。
- 選択範囲にオーバーレイ自体が含まれる場合でも、前回の英語が残り続けにくい挙動へ変更した。
