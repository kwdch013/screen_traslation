# 2026-06-03 翻訳範囲選択

## 作業内容

- 開始ボタン押下後、対象アプリ上に範囲選択用の半透明ウィンドウを表示し、ドラッグで翻訳範囲を指定できるようにした。
- 選択した範囲は対象ウィンドウ内の相対座標として保持し、対象ウィンドウを移動しても同じアプリ内範囲を追従キャプチャするようにした。
- 選択範囲が小さすぎる、または未選択の場合は翻訳を開始しないようにした。
- ステータスに対象ウィンドウ範囲と選択した相対範囲を表示するようにした。

## テスト

- 絶対座標と対象ウィンドウ内相対座標の相互変換を単体テストで確認した。
- 選択範囲がウィンドウ外にはみ出す場合に、ウィンドウ内へクランプされることを単体テストで確認した。
